# 🥗 Nourish — Food Assistant

Ek personalized food assistant web app jo users ko unke calorie goals, meal preferences aur allergies ke hisaab se food track aur recommend karne me help karta hai.

## Features
- User authentication (login/signup)
- Personalized profile (BMI, calorie target, allergies, preferences)
- Calorie tracking with daily goals
- AI-powered food image analysis (calories & nutrition estimate)
- Personalized food recommendations
- Chat-based nutrition assistant
- Dashboard with progress charts (calorie history, macros, weight trend)

## Tech Stack
- HTML, CSS, JavaScript (frontend)
- Anthropic Claude API (image analysis & chat)
- Chart.js (data visualization)
- Browser localStorage (data persistence)

## How to Run
1. Open `index.html` in any browser
2. Sign up / log in
3. Add your Anthropic API key in the Profile tab (needed for AI features)
4. Start logging meals!
